# 多模态RAG Demo 1

## 项目简介
多模态RAG（Retrieval Augmented Generation）是多模态信息检索和生成技术，用于处理多模态数据，如文本、图片、音频、视频等。
本项目描述了多模态RAG的实现，包括如何实现PDF结构解析、多模态信息提取、MD文本转化、文档切分和混合检索。

## 项目语言
Python，javascript，html，css

## 技术栈
**后端**：Python + LangChain + LangGraph + MinerU + Markdown
**前端**：HTML + CSS + JavaScript + Bootstrap + jQuery + Markdown

## 代码风格
1. 简洁优雅，符合开发规范
2. 不同的功能尽量做到模块化，可扩展
3. 必须用中文写好代码注释，标明每个类的功能，以及类成员变量含义，以及方法参数含义。

## 为什么放弃 unstructured + PaddleOCR（v2026-01 重大架构变更）

### unstructured + PaddleOCR 的问题

| 问题 | 详细描述 |
|------|----------|
| **坐标不对齐** | 元素框（bbox）与实际 PDF 内容位置不符，偏差约 1.69 倍 |
| **表格解析失败** | 复杂表格被解析为图片，无法转换为 Markdown 格式的表格文本 |
| **元素类型识别不全** | BulletedText 等元素类型未正确识别或分类错误 |
| **依赖复杂** | 需要同时安装 unstructured + PaddleOCR，配置繁琐 |

### 迁移到 MinerU 的原因

1. **专业 PDF 解析**：MinerU 是专门为 PDF 解析设计的工具，识别精度高
2. **坐标精确**：输出标准化的 JSON 格式，包含精确的 bbox 坐标
3. **表格支持**：支持表格检测和 OCR，真表格可提取为 Markdown
4. **开源免费**：MIT 许可证，可商用

### MinerU vs unstructured 对比

| 特性 | unstructured | MinerU |
|------|-------------|--------|
| PDF 解析精度 | 中等（坐标常出错） | 高（坐标精确） |
| 表格处理 | 图片输出 | 真表格可提取为 Markdown |
| 坐标系统 | 需手动处理坐标转换 | 直接输出可用坐标 |
| 安装配置 | 复杂（多依赖） | 简单（conda 环境） |
| 许可证 | Apache 2.0 | MIT |

### 坐标系统处理
MinerU 使用 PDF 坐标系（原点左下角，单位为 points），需要转换为浏览器像素坐标系（原点左上角）：

```python
# 计算缩放因子
scale_x = img_width / 595   # A4 页面宽度 595 points
scale_y = img_height / 842  # A4 页面高度 842 points

# 应用缩放
x0_scaled = int(x0 * scale_x)
y0_scaled = int(y0 * scale_y)
x1_scaled = int(x1 * scale_x)
y1_scaled = int(y1 * scale_y)
```

### 表格提取增强
MinerU 对表格的处理方式：

**MinerU 表格识别原理：**
- **真表格**（PDF 内置表格结构）：MinerU 能提取为 Markdown 格式
- **伪表格**（文本布局，如简历、教育背景）：MinerU 检测为表格但输出为图片

**处理策略：**
```python
# 1. 检查表格是否有 md 字段（真表格会返回 Markdown）
# 2. 如果是图片引用，显示为表格图片
# 3. 如果有文本内容，按空格分割尝试构建表格
```

**示例输出：**
- 真表格：`| 学校 | 专业 | 时间 |`
- 伪表格：`| [表格图片: xxx.jpg] |` + 说明文字

**支持的元素类型**：
| 类型 | 说明 | 颜色 |
|------|------|------|
| Title | 标题 | #FF6B6B (红) |
| NarrativeText | 段落文本 | #4ECDC4 (青) |
| BulletedText | 列表项 | #FFEAA7 (黄) |
| Table | 表格 | #45B7D1 (蓝) |
| Image | 图片 | #96CEB4 (绿) |
| Formula | 公式 | #DDA0DD (紫) |

## 需求描述

### 1. PDF结构解析
**功能：**
解析上传的PDF文件，并返回解析结果，包含PDF文件结构信息（如页数、页码、标题、段落、表格、图片、流程图等）以及每页的元素信息（如元素类型、位置、内容等）。

**后端：**
使用 `MinerU` 库解析上传的PDF文件，表格内容通过 `pdfplumber` 增强提取。解析结果通过接口方式，根据请求页展示对应页面解析内容（SVG 标注层）。

**前端：**
- 提供PDF上传界面，支持实时查看解析进度。
- 展示PDF解析内容，包括识别出的文档元素信息。
- 支持分页显示（默认第一页），用户可点击查看其他页。
- 可视化界面可及时查看解析情况。

**使用流程：**
1. 用户上传PDF文件，选择解析引擎（推荐 MinerU），点击"开始解析"。
2. 后台开始解析，并实时向前端返回解析进度。
3. 解析完成后，前端提示"解析完成，请查看解析结果"。
4. 用户可查看解析结果（默认第一页），确认无误后可进入MD文档转化步骤。

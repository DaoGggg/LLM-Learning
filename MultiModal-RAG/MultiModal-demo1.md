# 多模态RAG Demo 1

## 项目简介
多模态RAG（Retrieval Augmented Generation）是多模态信息检索和生成技术，用于处理多模态数据，如文本、图片、音频、视频等。
本项目描述了多模态RAG的实现，包括如何实现PDF结构解析、多模态信息提取、MD文本转化、文档切分和混合检索。

## 项目语言
Python，javascript，html，css

## 技术栈
**后端**：Python + LangChain + LangGraph + Unstructured + Matplotlib + PaddleOCR + Markdown
**前端**：HTML + CSS + JavaScript + Bootstrap + jQuery + Markdown

## 代码风格
1. 简洁优雅，符合开发规范
2. 不同的功能尽量做到模块化，可扩展
3. 必须用中文写好代码注释，标明每个类的功能，以及类成员变量含义，以及方法参数含义。

## 整体流程
1. PDF结构解析
2. 多模态信息提取（预留）
3. MD文本转化
4. 文档切分
5. 混合检索

## 需求描述

### 1. PDF结构解析
**功能：**  
解析上传的PDF文件，并返回解析结果，包含PDF文件结构信息（如页数、页码、标题、段落、表格、图片、流程图等）以及每页的元素信息（如元素类型、位置、内容等）。

**后端：**  
使用 `unstructured` 库 + OCR模型（百度 PaddleOCR）解析上传的PDF文件。  
解析结果通过接口方式，根据请求页使用 `matplotlib.pyplot` 绘制对应页面解析内容，并返回给前端。

**前端：**
- 提供PDF上传界面，支持实时查看解析进度。
- 展示PDF解析内容，包括识别出的文档元素信息（展示内容取决于`unstructured`库功能，避免因元素过多导致显示缓慢）。
- 支持分页显示（默认第一页），用户可点击查看其他页。
- 可视化界面可及时查看解析情况。

**使用流程：**
1. 用户上传PDF文件，点击“开始解析”。
2. 后台开始解析，并实时向前端返回解析进度。
3. 解析完成后，前端提示“解析完成，请查看解析结果”。
4. 用户可查看解析结果（默认第一页），确认无误后可进入MD文档转化步骤（预留多模态信息提取接口）。

### 2. 多模态信息提取（预留）
**功能：**  
提取图片、表格、流程图中的信息，针对不同类型的多模态内容采用不同的识别策略。

**说明：**  
此为 Demo 1，该功能暂时搁置，但需在架构中预留扩展空间，便于后续开发。

---

### 3. MD文本转化
**功能：**  
将第1步（及预留的第2步）提取的PDF信息转换为Markdown格式文本，便于用户查看转化效果并支持下载。

**后端：**  
需保留元素原有的结构关系，如段落、标题、表格、图片、流程图等。

**前端：**  
提供下载按钮，用户点击后可下载转化后的Markdown文件；也可选择不下载，直接进入下一步。

**使用流程：**
1. 用户在第一步确认无误后，后台开始将PDF信息转换为Markdown格式。
2. 返回下载链接，用户可选择下载Markdown文件或直接进入下一步。
